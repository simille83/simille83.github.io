Informativa sulla privacy - Hermes Agent

Ultimo aggiornamento: 24 novembre 2026

Chi usa l'app

Hermes Agent è un'applicazione privata usata esclusivamente dal suo proprietario, Simone Millefanti, sui propri account Google. Non è destinata a terzi.

Dati a cui accede

L'app richiede solo il permesso Gmail in sola lettura (gmail.readonly) per leggere, cercare e riassumere le email del proprietario.

Come vengono usati e conservati

  • I dati vengono elaborati solo su richiesta del proprietario, su un server di sua proprietà.
  • L'app non invia, non modifica e non cancella email.
  • I dati non vengono venduti, condivisi con terzi né usati per pubblicità.
  • Le credenziali di accesso sono conservate solo sul server del proprietario.

Uso dei dati delle API Google

L'uso delle informazioni ricevute dalle API Google rispetta le Google API Services User Data Policy, inclusi i requisiti di Uso Limitato (Limited Use).

Revoca

L'accesso può essere revocato in qualsiasi momento da myaccount.google.com/permissions.
